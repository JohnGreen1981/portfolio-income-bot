# Income Bot

Telegram bot for personal income and expense tracking.

This is a sanitized portfolio repository. The original working folder is not copied here directly.

## What It Demonstrates

- AI parsing of free-form finance messages.
- Receipt parsing and category grouping.
- Voice/photo/text input workflow.
- Google Sheets integration.
- Practical automation for personal finance operations.

## Portfolio Role

This project should show applied automation, multi-modal input, GPT parsing, and external-service integration.
